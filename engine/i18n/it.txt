# value the app puts in; a counting string has a form for each plural of the
# language, "one: … | other: …", and {n} is the count. tTerm, tTerm Web and
# names of terminals and machines are not translated. The page of tTerm Web
# has its own words, in tterm-web: these are the app's alone.

# ------------------------------------------------------------ vault: the Touch ID question for the vault of SSH keys
# macOS shows each in its own dialog for Touch ID or the Mac's password,
# after "tTerm is trying to": the end of that sentence, without a full stop.
# The system's own sentence in each language (macOS 26, APP_ASKING_AUTH in
# LocalAuthentication's UIAgent.loctable): most take an infinitive (de „Die
# App „tTerm“ möchte …“, fr « … » souhaite …, pl próbuje …, ru пытается …);
# in ja, ko and tr the string comes last, after a colon (ja …次の操作を実行し
# ようとしています: …, tr … şu işlemi yapmaya çalışıyor: …): a noun phrase.
vault.reason_open = aprire la tua cassaforte di tTerm
vault.reason_lock = consentire a questo Mac di aprire la tua cassaforte di tTerm
vault.reason_approve = consentire a un nuovo browser di aprire la tua cassaforte di tTerm
vault.reason_password = impostare una nuova password per la tua cassaforte di tTerm
